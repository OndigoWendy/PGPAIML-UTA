# University of Texas at Austin PGP AI/ML Projects

This repository collects projects completed as part of the University of Texas at Austin Postgraduate Program in Artificial Intelligence and Machine Learning: Business Applications.

## Projects in this repository

| Project | Focus | Methods and tools |
| --- | --- | --- |
| [FoodHub Data Analysis](PGPAIML-Projects/Foodhub/Learner_Notebook_Full_Code.ipynb) | Explore restaurant orders, customer ratings, preparation and delivery patterns, and business opportunities. | Python, pandas, exploratory data analysis, visualization |
| [Loan Modelling](PGPAIML-Projects/Loan/AIML_ML_Project_full_code_notebook.ipynb) | Predict which bank customers may accept a personal loan. | Classification, feature engineering, decision trees, model evaluation |
| [EasyVisa](PGPAIML-Projects/EasyVisa/EasyVisa_Full_Code.ipynb) | Predict employment-visa case outcomes and identify relevant factors. | Decision trees, ensemble methods, XGBoost, hyperparameter tuning, precision/recall/F1 evaluation |
| [Bank Churn Prediction](PGPAIML-Projects/BankChurn/Churn%20Prediction%20in%20Banking%20Using%20Neural%20Networks.ipynb) | Identify customers likely to leave a bank. | TensorFlow/Keras neural networks, SGD and Adam optimizers, dropout, SMOTE, recall-focused model selection |
| [Medical Assistant powered by RAG](PGPAIML-Projects/MadicalAssistantRAGProject/Medical%20Assistant%20powered%20by%20Retrieval-Augmented%20Generation.ipynb) | Prototype question answering over a medical reference document. | Document loading and chunking, sentence-transformer embeddings, Chroma vector search, LangChain, local Mistral model |
